# 8. Вклад участников команды

> Заполняется командой: укажите ФИО и фактически выполненные задачи. Ниже — разбиение
> работ проекта, которое удобно распределить между участниками.

| Участник | Направление | Работы |
|---|---|---|
| _ФИО 1_ | Проектирование БД | Анализ предметной области, ER-модель, нормализация, миграции 0001–0005, роли и права (0008) |
| _ФИО 2_ | Серверная логика и транзакции | Триггеры и функции (0002, 0003, 0009), аудит (0004), исследование конкурентного доступа, `concurrency-demo` |
| _ФИО 3_ | Приложение и аналитика | Сервис core (REST API, OpenAPI), SQL-отчёты и MV (0006), импорт (0007), оптимизация (0010), автотесты, Docker Compose |
| Все | Документация, IT-проекты | Диаграммы Чена, IDEF0, BPMN, архитектура; пояснительная записка |

Каждый участник должен уметь объяснить архитектуру, модель данных и механизмы
взаимодействия приложения с PostgreSQL (ТЗ, раздел 10).
